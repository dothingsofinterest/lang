# 项目说明

Learning any language's UI

# 技术架构

vite + react
NodeJS 20.16.0

# 注意：视频码率太高会导致 wavesurfer 卡顿

# 启动方法

1. 安装 npm install
2. 调试 npm run dev
3. 获得产物 npm run build 得到 /dist

# 使用方法

1. 根据英文/中文视频编写台词、单词、语法
2. 学习。看文稿学习单词和句子的发音、写法、含义、语法
3. 测试。
   看英语单词选含义
   听英语单词写出来
   看含义图像写英语单词
   听英语视频写英语句子/听中文视频写英语句子
