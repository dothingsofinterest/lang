# What is this?

The UI of this project.

# How to run?

1. npm install<br>
2. npm run dev<br>

# How to deploy?

1. npm run build<br>
2. Deploy the compiled output in the folders of "dist" & "node_modules" to a Node.js environment.<br>
3. Then start it: node dist/app.js<br>

# Dependencies

vite<br>
react<br>
NodeJS 20.16.0<br>
