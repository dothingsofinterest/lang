# What is this?

A tool for study languages through videos.

# How to start?

1. Install or Download the dependencies below<br>
   FFMPEG for windows<br>
   python<br>
   python's pyttsx3<br>
   BBC audiowaveform <br>
   Node.js 20.16.0 <br>
2. Config<br>
   Replace AUDIOWAVEFORM_PATH, <br>
   FFMPEG_PATH, <br>
   APP_LOG_PATH, <br>
   UPLOAD_PATH in "/webapi/.env" to your own paths<br><br>
   Replace APP_LOG_PATH in "/webserver/.env" to your own paths<br>
3. Start <br>
    1. cd /<br>
    2. npm install<br>
    3. npm run build<br>
    4. npm run start<br>
