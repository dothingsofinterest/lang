# What is this?

A tool for study languages through videos.

# How to start?

1. Install or Download the dependencies below<br>
   [FFMPEG for windows](https://www.ffmpeg.org/download.html)<br>
   python<br>
   [python's pyttsx3](https://github.com/nateshmbhat/pyttsx3)<br>
   [BBC audiowaveform](https://github.com/bbc/audiowaveform/releases/tag/1.10.2)<br>
   Node.js 20.16.0 <br>
2. Config<br>
   Replace AUDIOWAVEFORM_PATH, FFMPEG_PATH, APP_LOG_PATH, UPLOAD_PATH in "/webapi/.env" to your own paths<br><br>
   Replace APP_LOG_PATH in "/webserver/.env" to your own path<br>
3. Start <br>
    1. cd /<br>
    2. npm install<br>
    3. npm run build<br>
    4. npm run start<br>
