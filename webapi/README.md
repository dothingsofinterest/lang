# What is this?

The API of this project.

# How to run?

1. tsc<br>
2. npm run start<br>

# How to deploy?

1. tsc<br>
2. Deploy the compiled output in the folders of "dist" & "node_modules" to a Node.js environment.<br>
3. Then start it: node dist/app.js<br>

# Dependencies

NodeJS 20.16.0<br>
Express<br>
FFMPEG - video & audio<br>
pyttsx3 - text to speech<br>
BBC audiowaveform - audio waveform<br>
