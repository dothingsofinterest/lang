# What is this?

The API of the project.

# How to run?

1. tsc
2. npm run start

# How to deploy?

1. tsc
2. Deploy the compiled output in the folders of "dist" & "node_modules" to a Node.js environment.
3. Then start it: node dist/app.js

# Dependencies

NodeJS 20.16.0<br>
Express<br>
FFMPEG - video & audio<br>
pyttsx3 - text to speech<br>
